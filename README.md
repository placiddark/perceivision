# PERCEIVISION — Always-On Personal AI

An always-on personal AI with persistent memory, reusable skills, chosen
tool access, and cross-workflow task execution. A Helkhem53 hive project,
built for the Nebius x NVIDIA Global AI Hackathon — Personal AI track.

**Live:** https://placiddark.github.io/perceivision/

## The Four Pillars
1. **Persistent memory** — survives every session boundary
2. **Reusable skills** — procedural memory, loadable on demand
3. **Chosen tool access** — instruments held deliberately, per task
4. **Cross-workflow execution** — message to research to artifact to delivery
